# DreamJar

**English** | [简体中文](README.zh-CN.md)

A small, local-first web app for building money habits, inspired by the practices in Bodo Schäfer's money books for young readers. It is an independent project, not affiliated with the author or publishers, and contains no text from the books.

**Live app:** https://coracherry517.github.io/dreamjar/

## Features

- **Wishes and goals**: list up to 10 wishes, star the top 3, give each a price and a picture, and track savings. A 72-hour countdown nudges you to take the first step.
- **Success journal**: write at least five wins a day; streak counter included.
- **Income jars**: every income is split automatically (default 50% golden goose / 40% goals / 10% spending, adjustable).
- **Compound interest calculator**
- **Private by design**: data stays in your browser (IndexedDB). Export/import JSON backups.
- **Multilingual**: 简体中文, English, Deutsch, 日本語. Help add more!

## Run locally

```bash
npm install
npm run dev
```
