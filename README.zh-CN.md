# 梦想罐 DreamJar

[English](README.md) | **简体中文**

一个培养理财习惯的小型网页应用，灵感来自 Bodo Schäfer 面向青少年的理财读物中的实践方法。本项目为独立开源项目，与作者及出版方无关，不包含书中原文。

**在线使用：** https://coracherry517.github.io/dreamjar/

## 功能

- **愿望与目标**：写下最多 10 个愿望，选出最重要的 3 个，设置金额和图片，跟踪储蓄进度；72 小时倒计时提醒你迈出第一步。
- **成功日记**：每天记录至少 5 件成功的事，自动统计连续天数。
- **收入分罐**：每笔收入自动按比例分配（默认 金鹅账户 50% / 目标 40% / 花销 10%，可调整）。
- **复利计算器**
- **隐私优先**：数据只存在浏览器本地（IndexedDB），可导出、导入 JSON 备份。
- **多语言**：简体中文、English、Deutsch、日本語，欢迎贡献更多语言。

## 本地运行

```bash
npm install
npm run dev
```
